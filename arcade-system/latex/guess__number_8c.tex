\doxysubsection{Detailed Description}
Advanced number guessing game with difficulty levels and smart hints. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: CGI-\/based number guessing game featuring three difficulty levels (Easy/\+Medium/\+Hard), dynamic range hints, and intelligent feedback. Players guess a secret number within a limited number of attempts based on difficulty.

FA\+: بازی حدس عدد مبتنی بر CGI با سه سطح دشواری (آسان/متوسط/سخت)، راهنمایی بازه پویا، و بازخورد هوشمند. بازیکنان باید عدد مخفی را با تعداد محدودی تلاش (بر اساس سطح دشواری) حدس بزنند.
