\doxysubsection{Detailed Description}
Fibonacci-\/based 2048 puzzle game variant. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Puzzle game variant where tiles follow Fibonacci sequence instead of powers of 2. Players slide tiles to combine adjacent Fibonacci numbers. Two consecutive Fibonacci numbers merge to form the next number in sequence. Game ends when no valid moves remain.

FA\+: بازی پازل که در آن کاشی‌ها دنباله فیبوناچی را دنبال می‌کنند نه توان‌های 2. بازیکنان کاشی‌ها را برای ترکیب اعداد فیبوناچی مجاور می‌لغزانند. بازی زمانی به پایان می‌رسد که حرکت معتبری باقی نماند.

@responsibilities
\begin{DoxyItemize}
\item Manage 6x6 game board
\item Spawn new tiles (values 1 or 2)
\item Implement tile sliding mechanics
\item Validate Fibonacci merge rules
\item Prevent double-\/merging per move
\item Calculate score from merges
\item Check game over conditions
\end{DoxyItemize}

@interactions
\begin{DoxyItemize}
\item Receives\+: direction/board state parameters
\item Sends\+: HTML grid display with tile values and colors
\end{DoxyItemize}

@notes
\begin{DoxyItemize}
\item Board size\+: MAX\+\_\+\+SIZE = 6
\item Fibonacci sequence stored in FIB\+\_\+\+SEQ array
\item Each tile has color mapping
\item Special case\+: 1+1=2 always valid 
\end{DoxyItemize}
