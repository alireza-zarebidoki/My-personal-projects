Common utilities for CGI games and web content generation. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: This header file defines utility functions for CGI parameter handling, HTML content generation, and URL encoding/decoding. It provides essential infrastructure for the arcade system\textquotesingle{}s web-\/based games.

FA\+: این فایل هدر تعریف توابع کمکی برای دریافت پارامترهای CGI، تولید محتوای HTML و رمزگذاری/رمزگشایی URL را فراهم می‌کند. این ابزارها زیرساخت ضروری برای بازی‌های وب‌محور سیستم arcade هستند.

@responsibilities
\begin{DoxyItemize}
\item Extract query parameters from GET/\+POST requests
\item Generate proper HTML headers and footers
\item Handle URL encoding and decoding
\item Provide buffer management utilities
\end{DoxyItemize}

@notes
\begin{DoxyItemize}
\item MAX\+\_\+\+BUFFER is set to 1024 bytes
\item All string functions are bounds-\/checked
\item UTF-\/8 encoding is supported
