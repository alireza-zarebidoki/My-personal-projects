\doxysubsection{Detailed Description}
Game logic and move validation for Modified Checkers. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Core checkers logic implementation including piece movement rules, jump validation, forced jump detection and enforcement, piece promotion, and end-\/game conditions. Implements the complete rule set for checkers including multi-\/jump sequences and special piece behaviors (Man vs King vs Queen).

FA\+: پیاده‌سازی منطق اصلی چکرز شامل قوانین حرکت مهره، تایید پرش، تشخیص و اعمال پرش اجباری، ارتقاء مهره، و شرایط پایان بازی. پیاده‌سازی کامل مجموعه قوانین چکرز شامل دنباله‌های پرش چندگانه و رفتارهای خاص مهره (Man، King، Queen).

@responsibilities
\begin{DoxyItemize}
\item Validate piece movement rules for each type (Man, King, Queen)
\item Check direction constraints for movement
\item Validate jump moves (must jump over opponent pieces)
\item Detect available forced jumps
\item Enforce global forced jump rule
\item Handle piece promotion (Man to King at last row)
\item Support multi-\/jump sequences
\item Detect game over conditions (no pieces or no moves)
\item Check for stalemate/draw conditions
\end{DoxyItemize}

@interactions
\begin{DoxyItemize}
\item Called by\+: main.\+c (move validation and game state updates)
\item Uses\+: \doxylink{structCheckersState}{Checkers\+State} structure and piece types
\end{DoxyItemize}

@notes
\begin{DoxyItemize}
\item Man\+: diagonal forward only, becomes King at back row
\item King\+: all diagonal directions
\item Queen\+: vertical/horizontal with special rules
\item Forced jumps take priority over regular moves
\item Multi-\/jump sequences mandatory if available
\item Jump removes captured piece from board 
\end{DoxyItemize}
