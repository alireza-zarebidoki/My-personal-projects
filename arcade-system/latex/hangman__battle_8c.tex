\doxysubsection{Detailed Description}
Word guessing game (Hangman Battle) with PvP and Bot modes. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Two-\/player word guessing game (Hangman) featuring PvP mode or vs Bot. Players take turns guessing letters to reveal a hidden word. Game includes word banks, attempt limits, and visual hangman display.

FA\+: بازی حدس کردن کلمات (نبرد کلمات) با حالت‌های PvP یا بازی برابر بات. بازیکنان به نوبت حروف را حدس می‌زنند تا کلمه مخفی را آشکار کنند. بازی شامل بانک کلمات، محدودیت تلاش، و نمایش بصری hangman است.

@responsibilities
\begin{DoxyItemize}

\item Manage game state across turns
\item Track correct and incorrect guesses
\item Display partially revealed word
\item Draw hangman figure based on mistakes
\item Check win/loss conditions
\end{DoxyItemize}

@interactions
