\doxysubsection{Detailed Description}
Header file for Modified Chess game with custom pieces. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Defines game state structures and function prototypes for a modified chess game. Features custom pieces (Dragon, Thief, Gryphon) replacing standard Knights, Bishops, Rooks. Includes state serialization for persistence across HTTP requests, check/checkmate detection, and time control for both players.

FA\+: تعریف ساختارهای وضعیت بازی و نمونه توابع برای بازی شطرنج تغییر‌یافته. شامل مهره‌های سفارشی (اژدها، دزد، گریفون) جایگزین اسب، فیل، رخ معمولی. شامل سریال‌سازی وضعیت برای حفظ در درخواست‌های HTTP، تشخیص کیش/کیش‌مات، و کنترل زمان برای هر دو بازیکن.

@responsibilities
\begin{DoxyItemize}
\item Define piece types and game state structures
\item Declare game logic functions (movement, capture, check detection)
\item Provide state serialization/deserialization
\item Define board initialization functions
\end{DoxyItemize}

@interactions
