\doxysubsection{Detailed Description}
Header file for Modified Checkers game with custom pieces. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Defines game state structures and function prototypes for a modified checkers game. Features custom piece types (Man, King, Queen) with unique movement rules. Implements forced jump rules and multi-\/jump sequences. Includes state serialization for HTTP-\/based persistence and comprehensive game management.

FA\+: تعریف ساختارهای وضعیت بازی و نمونه توابع برای بازی چکرز تغییر‌یافته. شامل انواع مهره‌های سفارشی (Man، King، Queen) با قوانین حرکتی منحصربه‌فرد. پیاده‌سازی قوانین پرش اجباری و دنباله‌های پرش چندگانه. شامل سریال‌سازی وضعیت برای حفظ مبتنی‌بر HTTP و مدیریت بازی جامع.

@responsibilities
\begin{DoxyItemize}
\item Define piece types and game state structures
\item Declare game logic functions (movement, capture, jump validation)
\item Provide state serialization/deserialization
\item Define board initialization functions
\item Track forced jump requirements
\end{DoxyItemize}

@interactions
\begin{DoxyItemize}

\item Used by\+: Checkers CGI game module
\end{DoxyItemize}

@notes
\begin{DoxyItemize}
\item 8x8 board with pieces on dark squares only
\item Man\+: moves diagonally forward, becomes King at back row
\item King\+: moves diagonally any direction
\item Queen\+: moves vertically/horizontally with special rules
\item Forced jumps take priority over regular moves
\item Multi-\/jump sequences allowed in single turn 
\end{DoxyItemize}
