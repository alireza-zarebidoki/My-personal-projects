\doxysubsection{Detailed Description}
CGI interface and game rendering for Modified Chess. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Main CGI entry point for the modified chess game. Handles board rendering, piece movement validation, game state updates, and win condition checking. Displays chessboard with color highlights for selected pieces and valid moves. Includes pawn promotion UI and timer display.

FA\+: نقطه ورودی CGI اصلی برای بازی شطرنج تغییر‌یافته. مدیریت رندرینگ صفحه، تایید حرکت مهره، به‌روزرسانی وضعیت بازی، و بررسی شرایط برد. نمایش صفحه شطرنج با رنگ‌های برجسته برای مهره‌های انتخاب‌شده و حرکات معتبر. شامل رابط کاربری ارتقاء پیاده و نمایش تایمر.

@responsibilities
\begin{DoxyItemize}
\item Render 8x8 chessboard with piece graphics
\item Highlight selected pieces and valid moves
\item Process mouse clicks for piece movement
\item Display piece promotion menu when applicable
\item Update game state after valid moves
\item Check and display check/checkmate conditions
\item Manage player time and enforce time limits
\item Serialize game state for URL persistence
\end{DoxyItemize}

@interactions
\begin{DoxyItemize}
\item Receives\+: state (serialized game state), click (board coordinates)
\item Sends\+: HTML board display with embedded game state
\end{DoxyItemize}

@notes
\begin{DoxyItemize}
\item Board coordinates\+: click parameter format "{}rowcol"{} (e.\+g., "{}0701"{})
\item Each player has 10 minutes (600 seconds) initial time
\item Time decrements continuously during player\textquotesingle{}s turn 
\end{DoxyItemize}
