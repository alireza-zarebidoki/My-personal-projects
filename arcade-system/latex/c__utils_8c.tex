\doxysubsection{Detailed Description}
Implementation of CGI utilities and HTML generation functions. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Implements URL decoding, query parameter extraction from GET/\+POST, and HTML header/footer generation for the arcade games. Handles character encoding and buffer safety for CGI environment.

FA\+: پیاده‌سازی رمزگشایی URL، استخراج پارامترهای query از GET/\+POST، و تولید هدر/فوتر HTML برای بازی‌های arcade. مدیریت رمزگذاری کاراکتر و امنیت بافر را در محیط CGI انجام می‌دهد.

@responsibilities
\begin{DoxyItemize}
\item Parse query strings (GET and POST methods)
\item Decode URL-\/encoded characters (XX format)
\item Output proper Content-\/\+Type headers
\item Generate consistent HTML structure
\end{DoxyItemize}

@interactions
\begin{DoxyItemize}
\item Called by all game CGI modules
\item Processes QUERY\+\_\+\+STRING and REQUEST\+\_\+\+METHOD environment variables
\end{DoxyItemize}

@notes
\begin{DoxyItemize}
\item Supports POST with CONTENT\+\_\+\+LENGTH checking
\item Buffer overflow protection with size limits 
\end{DoxyItemize}
