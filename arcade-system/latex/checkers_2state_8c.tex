\doxysubsection{Detailed Description}
Game state management and persistence for checkers. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Handles initialization of checkers board with standard setup, serialization of game state to URL-\/safe strings, and deserialization from HTTP parameters. Manages piece positioning on dark squares only, turn tracking, forced jump state, and multi-\/jump tracking across HTTP requests.

FA\+: مدیریت آغاز صفحه چکرز با تنظیم استاندارد، سریال‌سازی وضعیت بازی به رشته‌های ایمن برای URL، و برعکس‌سازی از پارامترهای HTTP. مدیریت موقعیت مهره فقط روی خانه‌های تیره، تعقب نوبت‌ها، وضعیت پرش اجباری، و تعقب پرش‌های چندگانه در درخواست‌های HTTP.

@responsibilities
\begin{DoxyItemize}
\item Initialize game board with standard checkers setup
\item Place pieces on dark squares only (3 rows per side)
\item Serialize \doxylink{structCheckersState}{Checkers\+State} to compact URL-\/safe string
\item Deserialize HTTP parameters back to \doxylink{structCheckersState}{Checkers\+State}
\item Track current turn (RED/\+BLACK)
\item Manage forced jump requirements
\item Support multi-\/jump state persistence
\item Reset game state for new games
\end{DoxyItemize}

@interactions
\begin{DoxyItemize}
\item Called by\+: main.\+c (board initialization and updates)
\item Uses\+: \doxylink{structCheckersState}{Checkers\+State} structure from \doxylink{checkers_8h}{checkers.\+h}
\end{DoxyItemize}

@notes
\begin{DoxyItemize}
\item 8x8 board with pieces on dark squares (where row+col is odd)
\item Initial setup\+: 12 pieces per side (3 rows of 4)
\item RED pieces start at bottom, BLACK at top
\item State encoding\+: compact format for URL parameter transmission
\item Must preserve forced jump state across requests 
\end{DoxyItemize}
