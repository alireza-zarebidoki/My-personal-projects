\doxysubsection{Detailed Description}
Game logic and move validation for Modified Chess. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Core chess logic implementation including piece movement rules, move validation, check/checkmate detection, and stalemate checking. Handles special moves like pawn promotion and custom piece movement patterns (Dragon, Thief, Gryphon).

FA\+: پیاده‌سازی منطق اصلی شطرنج شامل قوانین حرکت مهره، تایید حرکت، تشخیص کیش/کیش‌مات، و بررسی استیل‌مت. مدیریت حرکات خاص مانند ارتقاء پیاده و الگوهای حرکتی مهره‌های سفارشی.

@responsibilities
\begin{DoxyItemize}
\item Validate individual piece movement rules
\item Check path clarity for sliding pieces
\item Count obstacles for custom pieces (Thief)
\item Detect check conditions for current player
\item Identify checkmate situations
\item Identify stalemate situations
\item Find available escape moves
\item Get all valid moves for a piece
\item Execute moves and update board state
\end{DoxyItemize}

@interactions
\begin{DoxyItemize}
\item Called by\+: main.\+c (move validation and execution)
\item Uses\+: \doxylink{structGameState}{Game\+State} structure and piece types
\end{DoxyItemize}

@notes
\begin{DoxyItemize}
\item \doxylink{structPiece}{Piece} movement patterns\+:
\begin{DoxyItemize}
\item Pawn\+: 1 forward (or 2 initial), capture diagonally
\item Gryphon\+: Rook-\/like + one diagonal move
\item Dragon\+: Knight-\/like + king-\/like moves
\item Thief\+: Bishop-\/like but can jump 1 obstacle
\end{DoxyItemize}
\item Full check/checkmate detection implemented 
\end{DoxyItemize}
