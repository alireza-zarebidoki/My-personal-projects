\doxysubsection{Detailed Description}
Game state management and persistence for chess. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Handles initialization of chess board with custom pieces, serialization of game state to URL-\/safe strings, and deserialization from parameters. Manages piece positioning, turn tracking, king location updates, and time management for both players.

FA\+: مدیریت آغاز صفحه شطرنج با مهره‌های سفارشی، سریال‌سازی وضعیت بازی به رشته‌های ایمن برای URL، و برعکس‌سازی از پارامترها. مدیریت موقعیت مهره، تعقب نوبت‌ها، به‌روزرسانی موقعیت شاه، و مدیریت زمان برای هر دو بازیکن.

@responsibilities
\begin{DoxyItemize}
\item Initialize game board with standard chess setup (modified pieces)
\item Place custom pieces (Dragon, Thief, Gryphon) in correct positions
\item Serialize \doxylink{structGameState}{Game\+State} to compact string format
\item Deserialize URL parameters back to \doxylink{structGameState}{Game\+State}
\item Track king positions for check detection
\item Manage elapsed time for each player
\item Reset game state for new games
\end{DoxyItemize}

@interactions
\begin{DoxyItemize}
\item Called by\+: main.\+c (board initialization and updates)
\item Uses\+: \doxylink{structGameState}{Game\+State} structure from \doxylink{chess_8h}{chess.\+h}
\end{DoxyItemize}

@notes
\begin{DoxyItemize}
\item Board is 8x8 standard chess layout
\item Custom pieces positioned same as standard equivalents
\item State format\+: compact URL-\/safe encoding for HTTP transmission
\item King positions automatically updated after moves 
\end{DoxyItemize}
