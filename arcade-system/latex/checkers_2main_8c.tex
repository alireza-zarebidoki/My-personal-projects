\doxysubsection{Detailed Description}
CGI interface and game rendering for Modified Checkers. 

@project arcade-\/system \begin{DoxyAuthor}{Author}
Alireza Zarebidoki @date\+\_\+modified 2025-\/12-\/25 
\end{DoxyAuthor}
EN\+: Main CGI entry point for the modified checkers game. Handles board rendering, piece selection and movement, forced jump enforcement, and game state updates. Displays checkers board with color coding for regular moves (green) and forced jumps (red). Includes multi-\/jump sequence support and win condition checking.

FA\+: نقطه ورودی CGI اصلی برای بازی چکرز تغییر‌یافته. مدیریت رندرینگ صفحه، انتخاب و حرکت مهره، اعمال پرش اجباری، و به‌روزرسانی وضعیت بازی. نمایش صفحه چکرز با کدگذاری رنگی برای حرکات معمولی (سبز) و پرش‌های اجباری (قرمز). شامل پشتیبانی دنباله‌های پرش چندگانه و بررسی شرایط برد.

@responsibilities
\begin{DoxyItemize}
\item Render 8x8 checkerboard with custom coloring
\item Highlight valid moves and forced jumps with colors
\item Process mouse clicks for piece selection and movement
\item Enforce forced jump rules
\item Support multi-\/jump sequences
\item Update board state after moves
\item Check for piece promotion (Man to King)
\item Detect game over conditions
\item Display game status messages
\item Serialize/deserialize game state for URL persistence
\end{DoxyItemize}

@interactions
\begin{DoxyItemize}
\item Receives\+: state (serialized game state), click (board coordinates)
\item Sends\+: HTML board display with embedded game state
\end{DoxyItemize}

@notes
\begin{DoxyItemize}
\item Board coordinates\+: click parameter format "{}rowcol"{} (e.\+g., "{}0701"{})
\item Pieces only on dark squares\+: valid row+col = odd
\item Forced jumps prevent regular moves
\item King promotion at last row 
\end{DoxyItemize}
